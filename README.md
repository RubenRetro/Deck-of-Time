# Deck of Time

A humorous blackjack game for MS-DOS, inspired by the golden age of 90s PC gaming.

## About

Deck of Time is a humorous blackjack game for MS-DOS, featuring a retro 90s PC gaming aesthetic and a healthy dose of humor.

The game was created for the **[Second MS-DOS Club DOS Game Programming Contest](https://msdos.club/foro/topic/segundo-concurso-de-programacion-para-juegos-dos-del-ms-dos-club/)**.
